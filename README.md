# ONEROMAN — сайт автофотографа

Что где лежит:

- `index.html` — разметка страницы
- `css/styles.css` — все стили
- `js/site-data.js` — **единственный файл, который  правим**: ссылки на фото и видео, тексты, список работ
- `js/main.js` — логика сайта 
- `assets/` — логотип `logo.png` и видео `bg.mp4` (видео нужно положить сюда)
